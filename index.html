Abstract摘要

AI 驱动科学的可重复性，还取决于运行计算工具的硬件。汇总指标稳定，不能保证证据选择和 Agent 决策也稳定。

我们在生产训练集群中发现了两种 GPU 静默数值故障模式：程序没有报错，训练持续运行，底层计算却已悄然发生偏差。Lei 等（OSDI’26）在覆盖 3,500 万 GPU 小时的生产部署中检测到 18 起 SDC 事件，涉及 13 张故障 GPU。OSDI’26 的另一项生产集群研究分析了 23 张出现静默数据损坏（SDC）的 GPU：标准合成微基准漏掉了超过 60% 的设备，常规 ECC 与温度保护也未捕获所观察到的逻辑级错误。因此，通过通用设备检查，并不等于某项具体科学计算可靠。

我们在健康硬件上回放捕获的工具数值。在原生 Biomni A1 Agent（GPT-6.1 Sol）执行的 hERG 筛查任务中，候选名单中的标注阻断剂数量保持不变，名单成员和检测分配却发生变化，甚至让参考决策要求送检的两个标注阻断剂不经检测直接推进。在 SciFact 检索列表发生变化的组合中，可出现“结论不变、证据路径改变”；未按这一条件筛选的队列中，差异未超出健康硬件重复运行时的波动。这两类实验共同说明：应同时检查汇总结果与产生科学决策的具体证据和对象。

为此，我们提出 BioAgent-DF，构建了一套从 GPU 数值校验、可信重算，到 Agent 状态恢复与决策认证的端到端科学决策保真框架。我们将研究从 hERG 药物安全筛查拓展到 GB1 蛋白工程和超导材料筛选，在三类任务中都观察到数值故障改变了 Agent 的决策。经 BioAgent-DF 恢复后，三个任务中的 Agent 决策均与匹配健康运行的参考决策一致。同时，与原始 FP64 校验相比，流式校验将额外验证耗时降低 78.2%，计算与验证总耗时降低 42.4%。

从生产集群中的静默数值故障，到科研 Agent 的决策保真，再到未来全自动湿实验室的发展，我们希望以 BioAgent-DF 为可信决策核心，将可信计算与科学决策的保障延伸至真实物理实验。我们的目标，是为下一代实验室构建贯穿计算、决策、执行与观测的可信基础设施。

让每一次科学决策有据可验，让每一步实验过程有迹可循，让每一项研究结论都能基于原始证据被重新审查与纠正。

Reproducibility in AI-driven science also depends on the hardware that produces tool values. Stable aggregate metrics do not guarantee that evidence selection or agent decisions will remain stable.

In production training clusters, we found two patterns of silent numerical faults on GPUs: programs reported no errors and training continued, while the underlying calculations had quietly diverged. Lei et al. detected 18 SDC incidents involving 13 faulty GPUs during a production deployment spanning 35 million GPU-hours. In another OSDI’26 study of 23 GPUs affected by silent data corruption (SDC), standard synthetic microbenchmarks missed over 60% of the defective devices, and conventional ECC and thermal protections did not capture the observed logic-level faults. Passing a general device test therefore does not establish correctness for a specific scientific computation.

We replay captured tool values in paired runs on healthy hardware. In hERG screening with the native Biomni A1 agent (GPT-6.1 Sol), the shortlist retains the same number of labeled blockers while shortlist membership and testing assignments change, including two labeled blockers advanced without testing, although the reference decision was to test them. In SciFact combinations selected for changed retrieval lists, verdicts can stay unchanged while evidence paths change; the unfiltered cohort shows no excess over healthy-repeat variation. Both experiments motivate checking the evidence and objects behind scientific decisions alongside aggregate results.

To address this, we propose BioAgent-DF, an end-to-end scientific decision-fidelity framework spanning GPU numerical verification, trusted recomputation, agent state restoration and decision certification. We extended our experiments from hERG drug safety screening to GB1 protein engineering and superconducting materials screening and observed that numerical faults changed agent decisions in all three tasks. After recovery with BioAgent-DF, agent decisions in all three tasks matched the reference decisions from matched healthy runs. Compared with the original FP64 verification, streaming verification reduces the added verification time by 78.2% and the total compute-and-verification time by 42.4%.

From silent numerical faults in production clusters to decision fidelity in research agents, we aim to make BioAgent-DF a trusted decision core that extends these safeguards to physical experiments. For future fully automated wet labs, this infrastructure would span computation, decisions, execution and observation.

Every scientific decision, verifiable against evidence.Every experimental step, traceable.Every conclusion, open to re-examination and correction from the original evidence.

BioAgent-DF for Next-Generation LabsBioAgent-DF：面向下一代实验室

Towards Trustworthy and Controllable Fully Automated Wet Labs

下一代全自动湿实验室既要自主设计和开展实验，也要判断哪些计算结果可信、哪些决策可以提交，以及出错后可以恢复哪些状态。我们在 hERG 检测分配任务中验证了计算与决策环节。线性层校验和检出了故障 GPU 上的全部受测故障来源，常规检查均未报警。Agent 使用错误数值后，仅替换文件无法纠正决策，恢复执行状态则可以。所有提交的决策均与认证结果一致。

我们希望将 BioAgent-DF 用于机器人和实验仪器。Agent 可以提前推理，仪器只在决策通过验证后执行操作。出错后可重建数字状态，并保留已执行的操作和测量记录。

Next-generation fully automated wet labs must design and run experiments, assess which computational results are trustworthy, and determine which decisions may be submitted and which states can be restored after an error. We validated the computational and decision steps in hERG testing assignment. Linear-layer checksums flagged every tested fault source, while routine checks raised no alerts. After the agent had used faulty values, replacing the file did not correct its decisions; restoring the execution state did. All submitted decisions matched the certificate.

We aim to apply BioAgent-DF to robots and instruments. The agent can reason ahead while instruments act only after a decision is verified. After an error, digital state can be rebuilt while retaining records of completed operations and measurements.

Validated in this work本文已验证

The native Biomni A1 agent runs GPT-6.1 Sol, with 224 standard tools and one hERG prediction tool. The decision rules are fixed before capture: select a shortlist of 402 compounds and assign hERG testing by a threshold. The prediction tool’s linear layers are checked with streaming checksums during the forward pass; flagged predictions are recomputed on trusted hardware, and certificates are issued by full trusted recomputation. Before the agent reads tool output, its execution state is saved: visible history, tool variables, derived files and pending decisions. The commit service checks the request, the certificate, the computational and decision settings, the input version, whether the decision agrees with the certified decision, and whether the request was already committed. Each request is committed at most once, and a commit is a local record.

原生 Biomni A1 Agent（GPT-6.1 Sol）配有 224 个标准工具和一个 hERG 预测工具。决策规则在捕获前固定，即选出 402 个化合物的候选名单，并按阈值分配 hERG 检测。预测工具的线性层在前向过程中接受流式校验和检查，被标记的预测在可信硬件上重算，证书由全量可信重算签发。Agent 读取工具输出前保存执行状态，包括对话历史、工具变量、派生文件和待执行决策。提交服务检查请求、证书、计算与决策设置、所依据的输入版本、决策与认证结果的一致性以及是否已提交，每个请求至多提交一次，提交是一条本地记录。

bTrusted computation: linear layers validated, other operators proposed可信计算：线性层已验证，其余算子为拟议

Validated in this work本文已验证

Row and column checksums with a rounding-error bound check linear computations of the form Y=XW⊤+bY = XW^{\top} + b. After deduplication there are 5,232 linear calculations: all 16 fault sources were flagged, eight healthy verifier runs raised no false alarm, and none of the 16 reference and restoration passes was flagged. By contrast, integrity checks on stored data and checks that probabilities are finite and between 0 and 1 flagged none of the 16 fault sources. An independent CPU implementation agreed on all calculations, and trusted recomputation on a healthy data-center GPU reproduced the reference bit for bit.

On the matched data-center GPU workload, streaming verification reduced the time for forward execution and verification from 1.02 s with the original FP64 checks to 0.59 s. The native forward pass took 0.47 s, and double execution took 0.88 s. Streaming verification reduced the added verification time by 78.2% and the total time by 42.4%, with 25.8% overhead over the native forward pass. Flags and recovery outputs were identical to the original implementation.

R1+M recovers decisions: R1 recomputes flagged predictions and M also recomputes the 68 compounds within ε of a decision boundary, after which the shortlist and testing assignments match the healthy reference in all 16 sources; the same number of compounds chosen at random or by ensemble disagreement left discrepancies. Full trusted recomputation provides certification: it issued every certificate in the single-request experiments.

对 Y=XW⊤+bY = XW^{\top} + b 形式的线性计算做行列校验和并附带舍入误差界。去重后共 5,232 次线性计算，16 个故障来源全部被标记，8 次健康验证运行无误报，16 次参考与恢复运行均未被标记。作为对照，存储完整性检查和“概率有限且在 0 到 1 之间”的检查对 16 个故障来源一个都没标出。独立的 CPU 实现与全部计算一致，健康数据中心 GPU 上的可信重算逐位复现参考。

在匹配的数据中心 GPU 工作负载上，流式校验把带校验的前向计算从原始 FP64 实现的 1.02 秒降到 0.59 秒。原生前向计算耗时 0.47 秒，双次执行耗时 0.88 秒。流式校验使额外验证耗时降低 78.2%，总耗时降低 42.4%，相对原生前向的开销为 25.8%。标记与恢复输出与原实现完全一致。

R1+M 恢复决策：R1 重算被标记的预测，M 再重算距决策边界不到 ε 的 68 个化合物，16 个来源的候选名单和分配全部与健康参考一致，而随机或按集成分歧选同样数量的化合物都留下了差异。全量可信重算提供认证：单请求实验中的证书均由它签发。

Proposed拟议

Extend verification to activations, attention, softmax, indexing and aggregation. We find that upstream numerical deviations can propagate through subsequent operators and change attention positions or model choices: all 2,048 rows of attention probabilities are finite and normalized, yet 58 change their maximum-attention position; under Case 1, finite LLM option scores still change the selected option. Certify decisions using a valid error bound for each score.

将校验扩展到激活、注意力、softmax 与索引、聚合等算子。我们发现上游数值偏差可经后续算子传播，并改变注意力位置或模型选择：2,048 行注意力概率全部有限且归一化，仍有 58 行的最大注意力位置改变；Case 1 条件下 LLM 的选项分数有限却改变了所选选项。用每个分数的有效误差界认证决策。

Why it matters意义

This work shows that finite values, error-free execution and unchanged metrics are not grounds for trust, and it gives a verification path that holds for linear layers. Extending coverage to other operators is the next step.

本文表明“数值有限、程序不报错、指标不变”都不构成可信依据，并给出一条对线性层成立的校验路径。覆盖面扩展到其他算子是下一步工作。

cHold, verify, restore, commit保持、验证、恢复、提交

Validated in this work本文已验证

Each of the 102 requests (16 fault sources plus one healthy reference, two tasks and three repeats) was evaluated under three recovery conditions. Verification before the agent read the table cost about 44,000 tokens per request. After the read, file replacement retained the previous execution state, and the commit service rejected all 96 decisions based on superseded faulty inputs, including 57 whose content matched the reference. Restoring the pre-read execution state allowed every request to submit the reference decision, at about 29,000 additional tokens and 5.66 ms of state operations per request. Across the three conditions, 306 outcomes included 210 commits, all consistent with the certificate and none duplicated. Section 01 compares recovery of the changed decisions.

16 个故障来源加 1 个健康参考，各两项任务、三次重复，共 102 个请求，分别在三种恢复条件下评估。验证先于 Agent 读取时，每个请求约使用 44,000 token。读取后只替换文件会保留旧执行状态；由于所依据的故障输入版本已经失效，提交服务拒绝了全部 96 个相关决策，其中 57 个决策本身与参考一致。恢复读取前的执行状态后，每个请求均提交了参考决策，每个请求额外使用约 29,000 token，状态操作耗时 5.66 毫秒。三种条件共 306 个结果、210 次提交，提交的决策全部与认证结果一致，且没有重复提交。第 01 节给出了这些决策的恢复结果。

Proposed拟议

Speculative execution overlaps the agent’s reasoning with verification in time to cut waiting latency. Isolation rules keep uncertified information out of the official database, shared memory and device interfaces, and away from other agents.

投机执行让 Agent 的推理与验证在时间上重叠，以减少等待延迟。隔离规则保证未认证信息不写入正式数据库、公共记忆和设备接口，也不传播给其他 Agent。

Why it matters意义

What this shows: replacing the file cannot recover the decision; the execution state must be rolled back, and every commit must check the input version. Speculation and isolation are designs built on top of this, and whether they pay off depends on the fault rate and the length of the experimental cycle.

已验证的结论是“仅替换文件无法纠正已形成的决策，必须回滚执行状态，且提交必须核对所依据的输入版本”。投机与隔离是在此之上的设计，是否值得取决于故障率和实验周期。

Why it matters意义

What this work demonstrates is joint recovery on the digital side: the tool state and the agent’s execution state are restored together. How to preserve irreversible physical facts is a new problem that sets fully automated wet labs apart from purely software systems.

eLong-term reliability长期可靠性

Validated in this work本文已验证

The Aritheia arithmetic-probe tool is public: on the faulty GPU, 15 of 69 checks detected an anomaly, and none did on two healthy GPUs. Healthy references were measured before, during and after every capture round. The residual bank keeps 16,437 residual records from 240 captures for replay. Ordinary precision differences serve as controls: between healthy environments, BF16 intermediate reduction changes Top-10 nearest-neighbor membership in the PBMC single-cell dataset; zero-residual controls leave endpoints unchanged; and differences between healthy repeats are measured separately as the comparison baseline.

Aritheia 算术探针工具已公开，故障 GPU 上 69 项检查中 15 项检出异常，两块健康 GPU 为零。每轮捕获前、中、后都测量健康参考。残差库保存了来自 240 次捕获的 16,437 条残差记录，可用于回放。普通精度差异已作为对照：健康环境之间的 BF16 中间降精度会改变 PBMC 单细胞数据集的 Top-10 近邻名单，零残差对照不改变终点，健康重复之间的差异被单独测量并作为比较基线。

Proposed拟议

Hardware drift monitoring and isolation; regression tests covering drivers, compute libraries, models and prompts; isolation, merging and revocation of memory; a digital twin; and 30 to 90 days of continuous operation.

硬件漂移监测与隔离；针对驱动、计算库、模型与提示词的回归测试；记忆的隔离、合并与撤销；数字孪生；30 到 90 天连续运行。

Why it matters意义

Long-term reliability has to be maintained continuously. This work provides three starting points: probes, reference measurements and replay data.

长期可靠性需要被持续维护。本文提供了探针、参考测量和回放数据三个起点。

01From tool state to scientific decisions从工具状态到科学决策

Streaming verification with conservative fallback带保守回退的流式校验

Our streaming checker shares signed and absolute FP64 tile reductions across row and column checks. A conservative arithmetic guard resolves checks when the original verifier’s decision is unambiguous and falls back to that verifier otherwise. Across the 16 evaluated fault sources, it preserved flags, localization and bitwise recovery outputs while reducing total forward-and-verification time by 42.4% relative to our original FP64 implementation.流式校验在行、列检查之间共享带符号与绝对值的 FP64 分块归约。当保守误差界足以确定原始校验器的判定时，直接给出结果；否则回退到原始校验器。在评价的 16 个故障来源中，标记、定位及逐位恢复输出均与原实现一致，前向计算与验证的总耗时比原始 FP64 实现降低 42.4%。

If the interval lies entirely above zero, flag the check; if it lies entirely below zero, pass it. An interval containing or touching zero triggers the original FP64 check. 03Recompute selected objects选择性重算Use arithmetic evidence and distance from selection or testing boundaries to choose further recomputation.结合异常位置，以及分数距入选线或检测阈值的距离，选择需要进一步重算的预测。

For fixed threshold and Top-K rules, let d(q) be the L∞ distance to the decision boundary. A rule output can change only if the score displacement reaches that boundary.对于固定阈值或 Top-K 选择，分数变了并不意味着名单一定会变。只有分数位移达到决策边界，规则输出才可能改变。下面用 d(q) 表示分数向量到边界的 L∞ 距离。

Suppose each score has a valid bound |si − p⋆i| ≤ ei. The admissible set lies within radius max ei of s. A radius smaller than d(s) cannot reach a boundary, so the rule is constant throughout the set.若每个分数具有有效误差界 |si − p⋆i| ≤ ei，可容许集合位于以 s 为中心、max ei 为半径的球内。半径小于 d(s) 时无法触及边界，规则在整个集合内为常值。

The non-negative ei bounds the error of score i. The admissible set is 𝒰 = {q : |qi − si| ≤ ei for every i}. Thus g(𝒰) is the set of decisions obtained from all score vectors allowed by these bounds.非负的 ei 是第 i 个分数的误差上界。可容许集合为 𝒰 = {q：对每个 i，都有 |qi − si| ≤ ei}。g(𝒰) 则是这些误差界允许的所有分数向量对应的决策集合。

max⁡iei<d(s) ⟹ g(U)={g(s)}\max_i e_i<d(s)\ \Longrightarrow\ g(\mathcal U)=\{g(s)\}

The displacement condition is necessary for a decision change; the interval condition is sufficient, not necessary, for certification.位移条件是决策变化的必要条件，区间条件是认证的充分而非必要条件。

03Mechanism机制

Selection turns small residuals into discrete changes排序竞争使细小残差改变入选对象

Tool outputs determine which items an agent can inspect, and selection is a competition. An unchanged score can still matter: for SciFact claim 684, one relevant document with an unchanged score leaves the top five after three competitors change, and restoring or transplanting any two competitor scores eliminates or reproduces the Recall@5 loss.工具输出决定 Agent 可以检查哪些对象，而选择取决于对象之间的竞争。对于 SciFact 声明 684，三个竞争文档的分数改变后，一个自身分数未变的相关文档退出前五名；恢复或移植任意两个竞争文档的分数，即可消除或重现 Recall@5 的下降。

Recombining captured residuals across a panel of eight executions keeps each call’s values but changes which differences occur together. Of 4,096 recombined executions, 29 produce lists absent from their source group, and the BF16 score grid with a lower-index tie rule explains all 1,024 enumerated combinations.在八次计算之间重组捕获的残差，保留每次调用的数值，但改变哪些差异共同出现。4,096 次重组计算中，有 29 次产生了其来源组中未出现过的名单；BF16 分数间隔及较小索引优先的平局规则可以解释全部 1,024 个穷举组合。
