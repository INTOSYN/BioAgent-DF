Abstract摘要

AI 驱动科学的可重复性，还取决于产生工具数值的硬件。汇总指标稳定，不能保证证据选择和实验决策也稳定。

我们在生产训练集群中发现了两类存在静默数值异常的 GPU：程序没有报错，训练持续运行，底层计算却已悄然发生偏差。OSDI’26 的两项生产集群研究也分别表征了 23 张存在静默数据损坏（SDC）的 GPU，以及覆盖 3,500 万 GPU 小时的在线检测部署。

我们将捕获的工具数值在健康硬件上配对回放。在 hERG 筛查中，候选名单中的标注阻断剂数量保持不变，送检名单和分派却发生变化，甚至将参考决策要求送检的两种标注阻断剂划为免检推进。在 SciFact 中，按检索列表已改变筛选的组合可出现“结论不变、证据路径改变”；未按这一条件筛选的队列没有观察到超出健康重复的差异。这两类实验共同说明：应同时检查汇总结果与产生科学行动的具体证据和对象。

为此，我们提出 BioAgent-DF，构建了一套从 GPU 数值校验、可信重算，到 Agent 状态恢复与决策认证的端到端科学决策保真框架。实验中，因故障而改变的 Agent 决策经状态恢复后，全部与健康运行下的参考决策一致。同时，相较于传统 FP64 校验方案，Streaming 流式校验将额外验证耗时降低 78.2%，计算与验证总耗时降低 42.4%。

从生产集群中的静默数值故障，到科研 Agent 的决策保真，再到未来的 Autonomous Wet Lab，我们希望以 BioAgent-DF 为可信决策核心，将可信计算与科学决策的保障延伸至真实物理实验，构建贯穿计算、决策、执行与测量的下一代自主实验室可信基础设施。

让每一次科学决策有据可验，让每一步实验过程有迹可循，让每一项研究结论都能基于原始证据被重新审查与纠正。

Reproducibility in AI-driven science also depends on the hardware that produces tool values. Stable aggregate metrics do not ensure stable evidence selection or experimental decisions.

In production training clusters, we found two classes of GPUs with silent numerical anomalies: programs reported no errors and training continued, while the underlying calculations had quietly diverged. Two OSDI’26 production-cluster studies also characterize 23 GPUs affected by silent data corruption (SDC) and an online detection deployment spanning 35 million GPU-hours, respectively.

We replay captured tool values in paired runs on healthy hardware. In hERG screening, the shortlist retains the same number of labeled blockers while shortlist membership and testing assignments change, including two labeled blockers routed to advancement without testing instead of the reference decision to test. In SciFact combinations selected for changed retrieval lists, verdicts can stay unchanged while evidence paths change; a cohort without this selection shows no excess over healthy-repeat variation. Both experiments motivate checking the evidence and objects behind scientific actions alongside aggregate results.

To address this, we propose BioAgent-DF, an end-to-end scientific decision-fidelity framework spanning GPU numerical verification, trusted recomputation, agent state restoration and decision certification. In our experiments, all agent decisions changed by the faults matched the healthy reference decisions after state restoration. Compared with the conventional FP64 verification baseline, streaming verification reduces the added verification time by 78.2% and the total compute-and-verification time by 42.4%.

From silent numerical faults in production clusters, through decision fidelity in research agents, to future autonomous wet labs, we aim to make BioAgent-DF a trusted decision core that extends reliable computation and scientific decision-making into physical experiments. Our goal is trusted infrastructure spanning computation, decisions, execution and measurement for the next generation of autonomous laboratories.

Every scientific decision, verifiable against evidence.Every experimental step, traceable.Every conclusion, open to re-examination and correction from the original evidence.

Outlook展望

BioAgent-DF for Next-Generation LabsBioAgent-DF：面向下一代实验室

Towards Trustworthy and Controllable Fully Automated Wet Labs

下一代自主实验室不仅要能独立提出和执行实验，还要知道哪些计算结果可以作为依据、哪些行动可以提交、错误发生后哪些状态可以恢复。本文在 hERG 评估分配任务上验证了这条链路的计算与决策两段：线性层校验和在真实故障 GPU 上全部报警而常规检查全部沉默；文件替换救不回已被 Agent 使用的错误值，恢复执行态可以；只有与证书一致的行动才被提交，没有一个错误行动通过。

BioAgent-DF 的目标是把这条链路延伸到机器人与仪器，让推理可以先行但不能提前改变实验，让数字状态可以重建但已发生的物理事实不被抹去。

Next-generation autonomous labs must do more than propose and run experiments on their own. They also need to know which computational results can serve as evidence, which actions may be committed, and which states can be restored after an error. On the hERG assay-allocation task, this work validates the computational and decision stages of that chain: on real faulty GPUs, linear-layer checksums flagged every faulty source while routine checks stayed silent; replacing the file could not recover faulty values the agent had already used, whereas restoring its execution state could; and only actions consistent with the certificate were committed, so no wrong action got through.

BioAgent-DF aims to extend this chain to robots and instruments, so that reasoning can run ahead without changing the experiment early, and digital state can be rebuilt without erasing physical facts that have already occurred.

Demonstrated in this work本文已验证

The research agent is the native agent A1 running GPT-6.1 Sol, with 224 standard tools and one hERG prediction tool. The decision rules are fixed before capture: select a shortlist of 402 compounds and route hERG testing by a threshold. The prediction tool’s linear layers are checked with streaming checksums during the forward pass; flagged predictions are recomputed on trusted hardware, and certificates are issued by full trusted recomputation. Before the agent reads tool output, its execution state is saved: visible history, tool variables, derived files and pending actions. The commit service checks the request, the certificate, the computation contract, the input view, whether the action agrees with the certified decision, and whether the request was already committed. Each request is committed at most once, and a commit is a local record.

科研 Agent 是原生 agent A1，模型为 GPT-6.1 Sol，带 224 个标准工具和一个 hERG 预测工具。决策规则在采集前固定，即选出 402 个化合物的候选列表，并按阈值分派 hERG 检测。预测工具的线性层在前向过程中接受流式校验和检查，被标记的预测在可信硬件上重算，证书由全量可信重算签发。Agent 读取工具输出前保存执行态，包括可见历史、工具变量、派生文件和待执行动作。提交服务检查请求、证书、计算契约、输入视图、行动与认证决策的一致性以及是否已提交，每个请求至多提交一次，提交是一条本地记录。

Why it matters意义

The demonstrated part answers what a decision was based on and whether it matches the decision under healthy hardware. The proposed part answers what actually happened at the bench.

bTrusted computation: linear layers demonstrated, other operators proposed可信计算：线性层已验证，其余算子为拟议

Demonstrated in this work本文已验证

Row and column checksums with a rounding-error bound check linear computations of the form Y = XWᵀ + b. After deduplication there are 5,232 linear calculations: all 16 faulty sources were flagged, eight healthy verifier runs raised no false alarm, and none of the 16 reference and restoration passes was flagged. By contrast, integrity checks on stored data and checks that probabilities are finite and between 0 and 1 flagged none of the 16 faulty sources. An independent CPU implementation agreed on all calculations, and trusted recomputation on a healthy data-center GPU reproduced the reference bit for bit.

The streaming implementation cut the verified forward pass from 1.02 s to 0.59 s, reducing the added verification time by 78.2% and the total time by 42.4%, with 25.8% overhead over the native forward pass and flags and recovery outputs identical to the original implementation.

R1+M recovers decisions: R1 recomputes flagged predictions and M also recomputes the 68 compounds within ε of a decision boundary, after which the shortlist and routing match the healthy reference in all 16 sources; the same number of compounds chosen at random or by ensemble disagreement left discrepancies. Full trusted recomputation provides certification: it issued every certificate in the per-request experiments.

对 Y = XWᵀ + b 形式的线性计算做行列校验和并附带舍入误差界。去重后共 5,232 次线性计算，16 个故障源全部被标记，8 次健康验证运行无误报，16 次参考与恢复通过均未被标记。作为对照，存储完整性检查和“概率有限且在 0 到 1 之间”的检查对 16 个故障源一个都没标出。独立的 CPU 实现与全部计算一致，健康数据中心 GPU 上的可信重算逐位复现参考。

流式实现把验证后的前向从 1.02 秒降到 0.59 秒，额外验证耗时降低 78.2%，总耗时降低 42.4%，相对原生前向的开销为 25.8%，标记与恢复输出与原实现完全一致。

R1+M 恢复决策：R1 重算被标记的预测，M 再重算距决策边界不到 ε 的 68 个化合物，16 个源的候选列表和分派全部与健康参考一致，而随机或按集成分歧选同样数量的化合物都留下了差异。全量可信重算提供认证：单请求实验中的证书均由它签发。

Proposed拟议

Extend verification to activations, attention, softmax and indexing, and aggregation. We find that upstream numerical deviations can propagate through subsequent operators and change attention positions or model choices: all 2,048 rows of attention probabilities are finite and normalized, yet 58 change their maximum-attention position; on Case 1 GPUs, finite LLM option scores still change the selected option. Certify decisions with the valid per-score error bounds of Corollary 1.

将校验扩展到激活、注意力、softmax 与索引、聚合等算子。我们发现上游数值偏差可经后续算子传播，并改变注意力位置或模型选择：2,048 行注意力概率全部有限且归一化，仍有 58 行的最大注意力位置改变；Case 1 GPU 上 LLM 的选项分数有限却改变了所选选项。以 Corollary 1 的有效逐分数误差界认证决策。

Why it matters意义

This work shows that finite values, error-free execution and unchanged metrics are not grounds for trust, and it gives a verification path that holds for linear layers. Extending coverage to other operators is the next step.

本文证明“数值有限、程序不报错、指标不变”都不构成可信依据，并给出一条对线性层成立的校验路径。覆盖面扩展到其他算子是下一步工作。

cHold, verify, restore, commit保持、验证、恢复、提交

Demonstrated in this work本文已验证

102 requests (16 fault sources plus one healthy reference, each with two tasks and three repeats) were each evaluated under three recovery conditions. With verification before the agent read the predictions, all 102 requests committed the healthy decision, using about 44,000 tokens per request.

When the agent had already read the faulty table and only the prediction file was replaced, none of the 39 changed decisions was recovered. The commit service rejected all 96 actions on faulty inputs because the input view used to prepare them had been superseded, including 57 actions that themselves agreed with the healthy decision.

When the execution state saved before the read was restored and the agent continued with the certified table, all 39 changed decisions were recovered, the other 63 stayed unchanged and all 102 requests were committed, at about 29,000 extra tokens and 5.66 ms of state operations per request. Across the three conditions, the 306 outcomes include 210 commits, none deviating from the certified decision and none duplicated.

102 个请求，即 16 个故障源加 1 个健康参考，各两项任务、三次重复，每个请求在三种恢复条件下分别评估。验证先于 Agent 读取时，全部 102 个请求提交了健康决策，每个请求约 44,000 token。

Agent 已读取故障表后只替换预测文件时，39 个改变的决策一个都没恢复，96 次故障输入上的行动全部被提交服务拒绝，原因是准备行动时的输入视图已被取代，其中 57 次行动本身与健康决策一致。

恢复到读取前保存的执行态并以认证表继续时，39 个改变的决策全部恢复，其余 63 个保持不变，102 个请求全部提交，每个请求额外约 29,000 token，状态操作每请求 5.66 毫秒。三种条件共 306 个结果，210 次提交无一偏离认证决策、无一重复。

Proposed拟议

Speculative execution overlaps the agent’s reasoning with verification in time to cut waiting latency. Isolation rules keep uncertified information out of the official database, shared memory and device interfaces, and away from other agents.

投机执行让 Agent 的推理与验证在时间上重叠，以减少等待延迟。隔离规则保证未认证信息不写入正式数据库、公共记忆和设备接口，也不传播给其他 Agent。

Why it matters意义

The demonstrated conclusion: replacing the file cannot recover the decision; the execution state must be rolled back, and every commit must check the input view. Speculation and isolation are designs built on top of this, and whether they pay off depends on the fault rate and the length of the experimental cycle.

已验证的结论是“换文件救不回，必须回滚执行态，且提交必须核对输入视图”。投机与隔离是在此之上的设计，是否值得取决于故障率和实验周期。

Why it matters意义

What this work demonstrates is joint recovery on the digital side: the tool state and the agent’s execution state are restored together. How to preserve irreversible physical facts is a new problem that sets autonomous labs apart from purely software systems.

本文证明的是数字侧的联合恢复，即工具状态和 Agent 执行态一起恢复。物理侧不可逆事实如何保留，是自主实验室区别于纯软件系统的新问题。

Demonstrated in this work本文已验证

The Aritheia arithmetic-probe tool is public: on the faulty GPU, 15 of 69 checks detected an anomaly, and none did on two healthy GPUs. Healthy references were measured before, during and after every capture round. The residual bank keeps 16,437 residual records from 240 captures for replay. Ordinary precision differences serve as controls: between healthy environments, BF16 intermediate reduction changes PBMC Top-10 membership; zero-residual controls leave endpoints unchanged; and differences between healthy repeats are measured separately as the comparison baseline.

Aritheia 算术探针工具已公开，故障 GPU 上 69 项检查中 15 项检出异常，两块健康 GPU 为零。每轮采集前、中、后都测量健康参考。残差库保存了来自 240 次捕获的 16,437 条残差记录，可用于回放。普通精度差异已作为对照：健康环境之间的 BF16 中间约简会改变 PBMC 的 Top-10 成员，零残差对照不改变终点，健康重复之间的差异被单独测量并作为比较基线。

Proposed拟议

Hardware drift monitoring and isolation; contract regression tests covering drivers, compute libraries, models and prompts; isolation, merging and revocation of memory; a digital twin; and 30 to 90 days of continuous operation.

硬件漂移监测与隔离；驱动、计算库、模型与提示词的契约回归测试；记忆的隔离、合并与撤销；数字孪生；30 到 90 天连续运行。

Why it matters意义

Long-term reliability has to be maintained continuously. This work provides three starting points: probes, reference measurements and a replay corpus.

长期可靠性需要被持续维护。本文提供了探针、参考测量和回放语料三个起点。

01From tool state to scientific action

Silent numerical faults change which compounds get tested静默数值故障改变了哪些化合物会被送检

A three-member Chemprop D-MPNN ensemble predicts blockade of the hERG potassium channel, a cardiac-safety liability, for 2,009 held-out compounds. A native Biomni A1 agent (GPT-6.1 Sol) selects the 402 highest-scoring compounds for measurement and assigns every compound to patch-clamp testing or advancement without testing. Sixteen saved BF16 passes, eight per fault class, are compared with a healthy reference from the same GPU model and host.

Case 1: size-dependent faults appear more often on the tested large-matrix paths than on short probes. Case 2: expanded-trigger faults also appear on short probes. Case 1 preserved shortlist membership and changed testing assignments in 1/8 sources; Case 2 changed shortlist membership in 6/8 and testing assignments in 6/8.

Every list replacement exchanged labeled blockers. The shortlist therefore still contained 351 labeled blockers among 402 compounds, even though its members and testing assignments changed. K12252 and K1461, both labeled blockers, were assigned to advancement without testing although the reference decision required testing. The changes extended beyond near-ties: K8429 fell from 0.880 to 0.584 and left the list, while K12096 and K2422 entered with unchanged predictions because competitors fell.

R1 recomputes on healthy hardware the predictions flagged by row and column checksums with a rounding bound. R1+M also recomputes the 68 compounds whose decision margin falls below ε = 0.009354. Selection and triage then matched the healthy reference in all 16 sources, and all 96 fresh Biomni trajectories on R1+M inputs reproduced the healthy decisions.

Certified commitment

Verify where the decision is committed

Execution provenance records the values used, and a complete record preserves an incorrectly computed value as faithfully as a correct one. Trust in an action therefore needs an independent check of the computation behind it.

Proposition 1

Fix a computation contract (inputs, model, numerical representation and execution settings), a candidate set and a tie rule. After round r, the admissible set Ur fixes exactly recomputed scores and bounds the others. A decision a may authorize action only if

g(q) = a for every q ∈ Ur

If the reference scores stay admissible, a certified decision equals the reference decision. If every uncertified round fixes at least one more score at its reference value, and fixed scores stay fixed, certification is reached within n rounds.

Algorithm 3 · certified commitment

  1. HoldHold tool outputs during independent arithmetic verification.
  2. RecomputeOn trusted hardware, recompute flagged predictions and scores whose decisions stay unresolved under valid bounds.
  3. RestoreIf the agent consumed a replaced output, restore its visible history and discard dependent state, pending actions and server-side caches.
  4. CertifyRecord the certified decision together with its supporting evidence.
  5. Commit onceCommit only actions that agree with the current certificate, at most once per request. If verification fails or the budget runs out, recompute every score on trusted hardware or commit nothing.

Cost on a healthy data-center GPU: streaming checks raise a 0.47 s forward pass to 0.59 s, against 1.02 s for the original FP64 implementation and 0.88 s for double execution.

02Method

Restore or transplant values at their original coordinates

We follow silent data corruption observed on faulty GPUs during distributed training. Finite, erroneous outputs can pass ordinary NaN/Inf monitoring and reach a tool result. Case 1 (size-dependent) GPUs fail more often on tested large-matrix paths than on short probes; Case 2 (expanded-trigger) GPUs also fail on those short probes.

With inputs, model, representation and document order matched, BioAgent-DF saves a reference state h and a candidate state c at the same computation site. Restoration and transplantation select values coordinate by coordinate. The remaining tool and agent steps run on healthy hardware, and repeated reference runs (H1, H2) measure how much the agent varies on its own.

03Mechanism

Selection turns small residuals into discrete changes

Tool outputs determine which items an agent can inspect, and selection is a competition. An unchanged score can still matter: for SciFact claim 684, one relevant document leaves the top five after three competitors change, and restoring or transplanting any two competitor scores recovers or reproduces the Recall@5 loss.

Recombining captured residuals across a panel of eight executions keeps each call’s values but changes which differences occur together. Of 4,096 recombined executions, 29 produce lists absent from their source group, and the BF16 score grid with a lower-index tie rule explains all 1,024 enumerated combinations.

Error decomposition

ΔMSE = 2 mean(eδ) + mean(δ²)

With reference error e and candidate–reference difference δ on the same evaluation rows, favorable alignment can reduce MSE even when selection changes.

04Endpoints

Identical losses and metrics can hide changed states

An eight-rank, two-node training continuation records 63 bitwise-identical FP32 losses with synchronized replicas, yet 30,411 parameters, 60,025 first moments, 105,921 second moments and all 1,017 FP64 predictions differ from the reference.

The direction of an effect can also depend on the healthy reference: the change in test RMSE reverses sign between RTX and NVLink environments. In SciFact, four of five new captures change which documents are retrieved while every query’s relevance-label sequence, Recall@5 and nDCG@10 stay the same.
